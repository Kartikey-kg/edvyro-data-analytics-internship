# Business KPI Dashboard

**Track:** Data Analytics
**Level:** Beginner-friendly
**Estimated time:** 60–90 minutes

## What you need to make

Build an interactive dashboard that explains churn, retention, revenue risk, and customer segments.

## Passing checklist

- [ ] Define churn rate, retention rate, revenue at risk, and tenure KPIs.
- [ ] Create filters for contract, tenure, and payment method.
- [ ] Use appropriate charts with clear labels and accessible colors.
- [ ] Put the work and a short explanation in one public or view-only link.

## What to submit

Submit one public or view-only link. Put supporting files in the same repository, folder, or project page so one link is enough.

## Optional portfolio upgrade

Add a written insight beside every major visual.

## Supplied material

- [Customer churn dataset](https://edvyro.in/datasets/customer_churn_sample.csv) — Use the cleaned dataset to define and visualise KPIs.

## Submission example

Share one GitHub repository, Google Drive folder, Figma file, YouTube video, or portfolio page that a reviewer can open without requesting access.
