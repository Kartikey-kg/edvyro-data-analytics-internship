# Executive Analytics Capstone

**Track:** Data Analytics
**Level:** Beginner-friendly
**Estimated time:** 2–3 hours

## What you need to make

Combine the analysis into a concise executive presentation with limitations, recommendations, and expected impact.

## Passing checklist

- [ ] Select the five insights that materially affect a business decision.
- [ ] Quantify impact ranges and state assumptions and limitations.
- [ ] Create a coherent narrative from problem to recommended action.
- [ ] Put the work and a short explanation in one public or view-only link.

## What to submit

Submit one public or view-only link. Put supporting files in the same repository, folder, or project page so one link is enough.

## Optional portfolio upgrade

Record a three-minute presentation of the final dashboard and findings.

## Supplied material

- [Customer churn dataset](https://edvyro.in/datasets/customer_churn_sample.csv) — Source data for the reproducible executive capstone.

## Submission example

Share one GitHub repository, Google Drive folder, Figma file, YouTube video, or portfolio page that a reviewer can open without requesting access.
